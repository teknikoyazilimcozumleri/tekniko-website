Kaynak: Iyzico Test Kartları. Sonuç sayfasında başarı/başarısızlık ve Iyzico hata mesajı gösterilir.

  1. Iyzico sandbox hesabı: sandbox-merchant.iyzipay.com üzerinden üye olun veya giriş yapın.
  2. API anahtarları: Panelde Ayarlar → API Anahtarları bölümünden API Key ve Secret Key alın.
  3. .env dosyası: Proje kökündeki .env içine IYZICO_API_KEY, IYZICO_SECRET_KEY, IYZICO_BASE_URL=sandbox-api.iyzipay.com yazın.
  4. Ödeme başlat: Yukarıdaki formda tutar ve para birimi girip "Ödeme sayfasına git" butonuna tıklayın.
  5. Test kartı: Iyzico sayfasında yukarıdaki tablodan seçtiğiniz senaryoya ait kart numarasını girin; SKT: 12/30, CVC: 123 kullanın.
Not: Callback için yerelde PAYMENT_CALLBACK_HOST veya ngrok kullanıyorsanız NGROK_PUBLIC_URL tanımlayın.
